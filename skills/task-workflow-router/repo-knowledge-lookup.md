# Repo-Knowledge Lookup

Use this mode when the user asks for a concrete command, documented process, deployment step, local setup detail, CI command, or repo-specific fact.

## Instructions

1. Search the repo for documentation and scripts before answering.
2. Prefer repo-local skills, README files, docs, package scripts, Makefiles, CI configs, and deployment scripts over guessing.
3. Cite the files or commands that establish the answer.
4. If the documented command depends on working directory, environment variables, credentials, or a venv, state those requirements.
5. If documentation and scripts disagree, report the mismatch instead of inventing a merged answer.

## Output

Give the concrete answer first, then short supporting context. Do not turn a lookup into an architecture discussion unless the discovered docs are inconsistent or risky.
